# BROF

**Office dosyalarını çift tıkla Google Docs, Sheets ve Slides'ta aç; düzenlemeler bilgisayarındaki dosyaya geri yazılsın.**
*Double-click an Office file to open it in Google Docs, Sheets or Slides; your edits are written back to the file on your computer.*

🌐 https://brof-app.netlify.app

Bu depo BROF'un Linux paketlerini ve paket tanımlarını barındırır; kaynak kod burada değildir.
*This repository hosts BROF's Linux packages and packaging files; it does not contain the source code.*

## Kurulum / Install

| | |
|---|---|
| **Windows** | [Microsoft Store](https://apps.microsoft.com/detail/9N91QTTXXCPL) |
| **Ubuntu ve Snap destekleyen dağıtımlar** | `sudo snap install brof` |
| **Arch, CachyOS, Manjaro (AUR)** | `yay -S brof-bin` ya da `paru -S brof-bin` |
| **AppImage (her dağıtım / any distro)** | [Releases](https://github.com/keremulusoy/BROF/releases/latest) sayfasından `BROF-…-x86_64.AppImage` dosyasını indir, çalıştırılabilir yap ve aç |
